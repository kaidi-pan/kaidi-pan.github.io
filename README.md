# Kaidi Pan (潘楷涤)

PhD student in philosophy at [Yale University](https://philosophy.yale.edu/) and a [Prize Teaching Fellow](https://gsas.yale.edu/teaching-fellow-program/prize-teaching-fellows).

**Website: [kaidi-pan.github.io](https://kaidi-pan.github.io/)**

My research interests range quite broadly. I usually start with philosophy of language; from there, I think about epistemology, normative reason, and persistent themes in the history of philosophy. Before Yale, I studied philosophy and linguistics at the University of Chicago.

## Research

Works in progress (drafts available by email):

- A paper on metaphysics of explanations and semantics of why questions
- A paper on forms of explanations in early analytic philosophy
- A paper on the moral psychology of akratic episodes

Undergraduate thesis: “Revealed Permissive Peer Disagreement: A Social Epistemological Pentalemma,” University of Chicago.

## About this repository

This is the source of [kaidi-pan.github.io](https://kaidi-pan.github.io/): plain HTML and CSS served by GitHub Pages, with no build step.

| File | What it is |
|---|---|
| `index.html` | Main page: Hello, Research, Teaching, Misc. |
| `jokes.html` | Philosophical Humors |
| `style.css` | Colours, type and layout |
| `photo.jpg` | Portrait (keep it under ~200 KB so the page loads fast) |
| `404.html` | Page shown for a broken link |
| `favicon.svg` | Browser-tab icon |
| `sitemap.xml`, `robots.txt` | Tell search engines which pages to index |

To update the site, open a file on GitHub, click the pencil icon, edit, and commit; the live site refreshes within a couple of minutes. When you change a page, also update its "Last updated" line and the matching `<lastmod>` date in `sitemap.xml`. If you add a new page, add it to `sitemap.xml` as well.
